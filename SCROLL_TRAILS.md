# Scroll-triggered trails

Each conceptual region in the MAP atlas has an authored camera path.

When a trail is active, wheel or vertical drag advances a continuous progress value instead of changing pages. That same progress drives both camera position and the explanatory graphics embedded in the region.

Current trails:

- Origin: reciprocal threat fades while a MAP bridge grows and the lineage resolves.
- Theory: membranes expose transfer and viability geometry, then resolve into the mechanically checked scalar convergence kernel.
- Application: network structure assembles and then resolves into an application test ledger.
- Intuition: local improvement becomes transferable progress along a visible path between distinct systems.

Free pan and semantic zoom remain available outside guided trails.
