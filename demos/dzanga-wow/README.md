# Dzanga wow pass

This is the flagship visual benchmark for the semantic-motion engine.

The goal is not documentary reconstruction. The visual grammar is inspired by the Dzanga-Sangha / Congo Basin rainforest: dense canopy, water, mist, animal corridors, mineral clearings (`bais`), roots, and layered ecological visibility.

## What this benchmark stresses

- semantic density increasing with zoom rather than simple magnification;
- persistent slow atmospheric motion using engine time signals;
- large colorful cascading bands that remain noticeable at macro scale;
- guided scroll choreography and free roam in the same world;
- animal motion strata at different semantic depths;
- scroll activity and direction as independent expressive signals;
- richer SVG art without abandoning GitHub Pages simplicity.

## Guided sequence

`river edge → closed canopy → animal corridor → mist threshold → bai → root/mineral underlayer`

## Review checklist

Desktop:
- ordinary wheel scrubs the guided route;
- Ctrl/⌘-wheel changes semantic depth around the pointer;
- +/- changes semantic depth around viewport center;
- Free roam restores direct pan;
- large color bands visibly drift even when input stops;
- bird/animal motion continues calmly without dominating the scene.

Mobile:
- one-finger drag scrubs in Guided mode;
- pinch changes semantic depth;
- Free roam allows direct pan;
- controls remain reachable without covering the focal clearing.

Reduced motion:
- runtime time signals stop continuously invalidating frames;
- the scene remains legible as a static semantic map.

## Art rule

**Dense, ecological, atmospheric. Never safari-poster.**

Animals populate fields and reveal relationships. They are not mascots or collectible objects.
