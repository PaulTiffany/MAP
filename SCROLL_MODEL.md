# Scroll-driven visual semantics

The explorer's motion is intentionally user-driven rather than decorative.

At the MAP center, camera position follows wheel, trackpad, or drag input continuously along the dominant axis and settles into the nearest authored lane. Once inside a lane, native vertical scrolling remains in control.

Within each lane, visible graphics are functions of scroll progress. Transfer markers, viability regions, threat-to-transfer inversion, application reveals, lineage assembly, and the Lean curve are scrubbed from the reader's position instead of running on autonomous loops.

The goal is simple: movement should teach the relation. The interface should not animate merely because it can.
