# Visual semantic layers

The atlas reveals different representations of the same MAP object by scale.

1. Geography — the four conceptual regions and their relation to MAP.
2. Relations — membranes, deterrence/transfer, networks, and intuitive flow.
3. Mechanisms — transfer operators, viability conditions, provenance, and application tests.
4. Formal — Principia labels, status language, and the Lean convergence kernel.

The layers cross-fade rather than swapping pages. The semantic zoom model is therefore continuous both spatially and epistemically.
